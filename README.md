 Breast Cancer Classification using ANN

 Overview

This project applies Machine Learning (Artificial Neural Network) to classify breast cancer tumors as **malignant** or **benign** based on medical features.

---

 Dataset

The dataset contains multiple features such as:

* Radius
* Texture
* Perimeter
* Area
  ...and more

The target variable:

* M → Malignant (1)
* B → Benign (0)

---

 Technologies Used

* Python
* Pandas & NumPy
* Scikit-learn
* TensorFlow / Keras
* Matplotlib & Seaborn

---

 Workflow

1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Preprocessing & Scaling
5. Train-Test Split
6. Building ANN Model
7. Model Training
8. Model Evaluation

---

 Model Architecture

* Input Layer
* Hidden Layer (16 neurons, ReLU)
* Hidden Layer (8 neurons, ReLU)
* Output Layer (Sigmoid)

---

 Evaluation Metrics

* Accuracy
* Confusion Matrix
* Classification Report
* ROC Curve

---

 Results

The model achieved good performance in classifying tumors with high accuracy.
